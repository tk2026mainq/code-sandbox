# code-sandbox

게임 엔진 없이 게임/그래픽 프로그래밍의 기초를 직접 만들어보는 개인 학습 저장소입니다.

## 왜 이 레포를 만들었나
- 거창한 완성작보다, **내가 실제로 이해하고 재사용할 수 있는 코드**를 만드는 것이 목표입니다.
- GitHub에서 작은 단위로 기록하고, 꾸준히 성장하기 위한 첫 발판입니다.

## 현재 방향
- 언어: **Python**, **C++**
- 주제: 그래픽 기초, 게임 루프, 수학/벡터, 충돌 판정, 간단한 물리 시뮬레이션
- 원칙: 작은 기능을 직접 구현하고 실험하면서 개념을 익히기

## 작은 로드맵
1. 화면 갱신 + 입력 처리 + 델타타임이 있는 기본 루프 만들기
2. 벡터/행렬 등 게임 수학 유틸리티 정리
3. AABB/원 충돌 같은 기초 충돌 판정 구현
4. 중력, 속도, 가속도 기반의 아주 단순한 물리 업데이트 작성
5. Python 프로토타입을 C++로 옮기며 성능/구조 비교

## 작업 방식
- 한 번에 크게 만들지 않고, 작은 실험 단위로 커밋하기
- 실패한 실험도 기록해서 다음 시도에 활용하기
- "지금 당장 내가 쓸 수 있는가?"를 기준으로 개선하기
